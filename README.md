# AI Linux Log Anomaly Detector

## Overview
This project uses Machine Learning to detect anomalies in Linux system logs such as auth.log.

## Features
- Detects brute force attacks
- Identifies suspicious login patterns
- Highlights unusual sudo usage

## Tech Stack
- Python
- Scikit-learn (Isolation Forest)
- Pandas

## Use Case
Helps security teams identify threats in real-time from system logs.

## Future Improvements
- SIEM integration
- Real-time streaming logs
- AI model tuning
